Privacy policy — R3NOVATION Backup

Effective date: 18 October 2026. Operator: R3PORTME. This policy describes a personal, single-user desktop rclone + restic backup setup and these two static information pages. It is not a service accepting other users' data.

Google access and use of data

The owner personally authorizes Google Drive OAuth. The current scope, https://www.googleapis.com/auth/drive, permits reading, creating, changing and deleting files across the authorized account, not just one folder. Configured backup operations use the owner's selected folder and explicitly selected backup inputs.

The local tools use Drive file/folder metadata, such as object names, identifiers, permissions and sizes, to locate the approved repository and perform transfers. Selected source bytes are read locally for backup; encrypted repository bytes are uploaded to Drive or downloaded for restoration and verification. Restic encrypts backup content locally before transfer. Drive still processes encrypted object storage and request metadata.

Google user data is used only for the owner's backup and restore functionality. This application does not sell it, use it for advertising, or use it to train AI or machine-learning models.

Storage, sharing and retention

OAuth tokens and the restic password remain in private local configuration files. The owner retains an independent recovery-password copy. This website and its public repository do not store those secrets, backup inputs, backup manifests or backup contents.

Encrypted backup objects are stored in the owner's selected Google Drive folder with its existing sharing permissions. People with access to that folder can access the encrypted objects; editors may delete, corrupt or roll them back. Encryption protects content confidentiality but does not prevent those actions. Local originals and recovery copies are preserved.

The configured workflow does not automatically prune or delete backups. Local configuration and backup objects remain until the owner separately removes them or the relevant storage provider applies its policies. The owner can stop the local backup job and revoke the application's Google access through Google Account settings. Revoking access does not delete stored backups; losing the recovery password can make encrypted contents unrecoverable.

Information pages and contact

These static pages contain no forms, scripts or analytics and set no application cookies. They do not handle Google sign-in or receive OAuth tokens or backup data. GitHub Pages hosts the pages and may process connection information, including IP addresses and request metadata, under GitHub's own policies.

For support or privacy questions, contact the operator through the public R3PORTME GitHub profile.
