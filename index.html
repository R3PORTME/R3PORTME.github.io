R3NOVATION Backup

A personal, single-user desktop backup setup operated by R3PORTME. It uses rclone for Google Drive OAuth and transport, and restic for client-side encryption, versioned backups and verified restores. This is an information page, not a hosted backup service or a sign-in portal.

Google Drive access

The owner authorizes the desktop application directly with Google. Its current OAuth scope is https://www.googleapis.com/auth/drive: permission to read, create, change and delete files across the authorized Drive account. This permission is broader than one folder. The configured backup operations use an owner-selected folder; that configuration does not limit what the OAuth permission permits.

File and folder metadata are used to locate the selected repository and transfer its contents. Only owner-selected backup inputs are processed locally. Restic encrypts their contents before upload; Drive receives encrypted repository objects and their associated storage/request metadata.

Storage and control

OAuth tokens and the restic password are kept in private local files on the owner's computer. The owner separately retains a recovery-password copy. They are not stored on this website or in its public source repository.

The selected Drive folder is shared under the owner's existing settings. Other editors may delete, corrupt or roll back encrypted backup objects. Encryption does not prevent that, and local originals are retained.

These static pages have no forms, scripts, analytics or application-set cookies. They do not receive backup files or OAuth credentials. GitHub Pages provides the web hosting.
